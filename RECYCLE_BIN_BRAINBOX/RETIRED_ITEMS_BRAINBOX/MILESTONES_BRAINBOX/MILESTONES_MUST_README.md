## 1. Purpose

This README is the local authority for milestone records stored in this folder.

The milestone checkpoint is a global, jointly maintained record. It must not be framed as the private or exclusive compilation of one AI agent.

## 2. Global Milestone Record Rule

`MILESTONE_CHECKPOINT_BRAINBOX.md` is maintained jointly by participating AI agents under operator authority.

Any participating agent may update the milestone record when explicitly instructed and when the change is supported by verified evidence.

No single-agent authorship claim should be used to establish exclusive ownership of the global checkpoint.

## 3. Naming and Record Rules

- Milestone records in this folder use the established `_BRAINBOX` suffix.
- Supporting authority or appendix records must follow the same naming discipline unless explicitly authorized otherwise.
- Deleted or superseded records must not be recreated merely to preserve obsolete attribution.
- Changes must preserve the distinction between verified, unverified, planned/deferred, and historical information.

## 4. Explicit Example — What Not To Do

`APPENDIX_GROK_MILESTONE.md` is a historical example of a separate single-agent appendix attached to the global checkpoint.

It was removed because the milestone checkpoint is a global, jointly maintained record and the separate appendix introduced conflicting authorship framing.

**Do not recreate this appendix or use it as a model for future milestone ownership.**

The example is recorded here for governance/history purposes only; its file contents are intentionally not retained in the folder.

## 5. Authority

This README governs milestone-folder-specific rules.

1. `DOB_MUST_README.md`
2. `AI_BRAINBOX/AI_MUST_README.md`

The global milestone checkpoint remains the canonical milestone record for this folder.
