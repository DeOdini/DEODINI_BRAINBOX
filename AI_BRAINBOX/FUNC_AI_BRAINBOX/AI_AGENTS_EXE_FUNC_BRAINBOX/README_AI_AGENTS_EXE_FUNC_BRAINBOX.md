## Use and limits

- Every category record identifies the execution evidence, executor, date, boundaries, and source links.
- Current connection/authentication must be checked in the relevant runtime before relying on a historic execution.
- An admitted capability does not grant standing authority to write, send, publish, deploy, push, or merge.
- MEDIA remains a reserved candidate slot until a successful output artifact is independently recorded.
- CORE records link to admitted categories or state why no agent category is assigned.
