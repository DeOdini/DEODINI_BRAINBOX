## Ownership and documentation boundaries

This directory is the canonical Brainbox location for FootHive V02 project documentation. The project-owned conversation below is the canonical destination for future V02 discussion and decisions; the copied MAIN CONVO 4 body is a bounded historical source, not a second evolving conversation. This directory does not own or replace the external FootHive application source repository, Sandbox workflow-trial evidence, Production operation evidence, or Portfolio presentation records.

POST-V003 records own changes to the Brainbox system itself, including authorized changes to its structure and navigation. Project requirements, project conversations, design specifications, implementation tickets, project reports and application assets belong to the FootHive V02 project domain. A Brainbox structural change may be summarized in POST-V003 with a precise reference; the complete project record should remain with its project owner.

Do not copy historical Iteration 01 material here, rewrite its source, or treat a cross-reference as permission to move content. Preserve source provenance and evidence status.

## Relationship to FootHive versions and workflow iterations

FootHive V01 and V02 refer to website/project versions. Workflow Iteration 01, 02 and 03 refer to separate experimental workflow iterations. These are distinct dimensions; a website version does not establish which workflow iteration occurred.

The existing [FootHive workflow-trial record](../FOOTHIVE_POC_BRAINBOX/README_FH_WORKFLOW_TRIAL_BRAINBOX.md) remains the canonical source for its existing Iteration 01 dataset and history. RECT-04 copies none of that evidence and makes no claim that V02 has been implemented or tested. Future iteration records require their own evidence and authorization.
